# Telnyx Electron Next.js App 🚀

Welcome to the **Telnyx Electron Next.js App** repository! This project combines the power of Electron and Next.js to create a Progressive Web App (PWA) that leverages Telnyx's communication APIs. This app supports both inbound and outbound calls, SMS, and real-time communication features using WebRTC.

## Features

- **Inbound and Outbound Calls**: Make and receive calls seamlessly using Telnyx's powerful APIs.
- **SMS Integration**: Send and receive SMS messages directly from the app.
- **WebRTC Support**: Utilize WebRTC for real-time communication.
- **Progressive Web App**: Enjoy offline capabilities and enhanced performance.
- **Cross-Platform**: Runs on Windows, macOS, and Linux.
- **User-Friendly Interface**: Designed with a focus on simplicity and ease of use.

## Technologies Used

This project utilizes a variety of technologies to deliver a robust user experience:

- **Next.js**: A React framework for server-side rendering and static site generation.
- **Electron**: Framework for building cross-platform desktop apps using web technologies.
- **TypeScript**: A typed superset of JavaScript that compiles to plain JavaScript.
- **React.js**: A JavaScript library for building user interfaces.
- **Supabase**: An open-source Firebase alternative for backend services.
- **Telnyx**: A communication platform that provides APIs for voice, messaging, and more.
- **WebRTC**: A technology that enables real-time communication directly in web browsers.

## Installation

To get started with the Telnyx Electron Next.js App, follow these steps:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/ygor08/telnyx-electron-nextjs-app.git
   cd telnyx-electron-nextjs-app
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Set up environment variables**:

   Create a `.env` file in the root directory and add your Telnyx API credentials:

   ```
   TELNYX_API_KEY=your_api_key
   SUPABASE_URL=your_supabase_url
   SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Run the app**:

   ```bash
   npm run dev
   ```

   Your app should now be running at `http://localhost:3000`.

## Usage

After installation, you can start using the app. Here’s a brief overview of how to navigate through its features:

- **Making Calls**: Click on the "Call" button, enter the phone number, and hit "Dial".
- **Receiving Calls**: When a call comes in, a notification will appear. Click "Answer" to accept the call.
- **Sending SMS**: Navigate to the SMS section, enter the recipient's number and your message, then click "Send".
- **Checking Call Logs**: Access the call logs from the main menu to view your call history.

For more detailed instructions, refer to the documentation provided in the repository.
